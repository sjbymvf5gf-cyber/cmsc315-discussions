1. What concepts or skills did you learn while completing this assignment?
During this unit, I learned about the use of bubble and merge sorting. Bubble sorting identifies the values and 
compares them to the one next to each other and sort items. Merge sorting does it a little different, as it 
divides the list into smaller parts, comparing each item and then combining them once all have been sorted.
2. What challenges did you encounter, and how did you overcome them?
As with the lab, merge sorting was a little trickier to comprehend. I had to be able to compare the divided lists
in order to create a finalized sorted list. 
3. Compare and contrast each sorting algorithm based on efficiency differences, tradeoffs made, and when to each.
Bubble sorting method is easier to understand and implement than merge. It will use the complete list of values to 
start comparing against the one next to each other and sort the list. For this having a short list or one that is 
partially sorted would mostly benefit from bubble sort as it would require not that much memory to complete. Merge 
sort would be most beneficial when the list is large in size, as it breaks down the list into parts. Once it has 
sorted each part, it will combine them to have a complete sorted list.
